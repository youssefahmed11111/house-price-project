# House Price Prediction

## Project Overview

This project analyzes a real estate dataset and builds machine learning models to predict house prices.

## Dataset

The dataset contains 187,531 property records and 21 columns.

## Data Preparation

The data was cleaned by removing unnecessary columns, converting prices and carpet areas into numerical values, handling missing values, and preparing categorical features.

## Exploratory Data Analysis

Four visualizations were created:

1. Price Distribution

2. Price vs Carpet Area

3. Average Price by Top 15 Locations

4. Price by Furnishing Type

## Machine Learning Models

Two Random Forest regression models were trained:

- Random Forest Regression

- Log-transformed Random Forest Regression

## Evaluation

The models were evaluated using:

- Mean Absolute Error (MAE)

- Root Mean Squared Error (RMSE)

- R² Score

The Log-transformed Random Forest achieved the better overall results.

## Tools

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, and Joblib.
